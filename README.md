Python Data Analysis Project

About

This project demonstrates basic data analysis using Python and Pandas.

Files

- "Data-analysis.py": Displays student marks, calculates average marks, and identifies the topper.
- "data_analysis.py": Displays student marks and calculates average, highest, and lowest marks.

Features

- Display student names and marks.
- Calculate average marks.
- Find the highest and lowest marks.
- Identify the topper.

Technologies Used

- Python
- Pandas
